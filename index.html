Real-time multiplayer Cabo, the memory card game where the lowest hand wins. Start a room, share the link and play with friends in the browser.

  • TypeScript
  • Node.js
  • Socket.IO

Car Simulator

A home-built driving rig with a real steering wheel and pedals. An Arduino reads every control and a Python script turns it into a virtual game controller.

Stack

  • Arduino UNO
  • C++
  • Python
  • ViGEmBus

Highlights

  • Seven controls: accelerator, brake, clutch, steering, gear up, gear down and handbrake
  • Rotary encoder reads the steering; potentiometers give variable accelerator and brake
  • Clutch, gear shifters and handbrake run on limit switches
  • Arduino streams every reading to Python over serial
  • Games see it as a regular controller through a virtual gamepad
