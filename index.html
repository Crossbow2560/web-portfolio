Car Simulator

  • C++
  • Python
  • ViGEmBus

Highlights

  • Seven controls: accelerator, brake, clutch, steering, gear up, gear down and handbrake
  • Rotary encoder reads the steering; potentiometers give variable accelerator and brake
  • Arduino streams every reading to Python over serial
  • Games see it as a regular controller through a virtual gamepad

AgentSecureBench

Summer 2026 internship · PES Innovation Lab (PIL)

A Python framework for security-testing LLM agents against the OWASP Top 10 for Agentic Applications, built as a team.

Stack

  • Python
  • Pydantic
  • OpenAI
  • Anthropic
  • Gemini
  • Ollama
  • llama.cpp

Highlights

  • One adapter interface for OpenAI, Anthropic, Gemini, Ollama and llama.cpp: swap the model without touching the agent
  • Every LLM call, tool call and memory change is logged and fully replayable, with per-message provenance
  • Persistent agent memory with keyword or embedding search, used to test memory and context poisoning
  • Memory-poisoning benchmark of 200 attack / benign prompt pairs, run model by model in batches
  • Tool registry with risk tiers and provider-native tool schemas
