DBase

A self-hosted file storage and sharing app, like a small Google Drive you run on your own server.

Stack

  • TypeScript
  • Node.js
  • Fastify
  • Prisma
  • Postgres (Supabase)
  • MinIO
  • Next.js
  • React
  • Tailwind CSS
  • Docker

Highlights

  • Share files and folders with other users, or through public links with an optional password and expiry date
  • Two-way folder sync from your desktop using a CLI client
  • Thumbnails and in-browser previews for images, videos and PDFs
  • Global search, tags, favorites, and a trash that keeps deleted items for 30 days
  • Admin panel for managing users, storage quotas, backups and the audit log

02

Cabo

Real-time multiplayer Cabo, the memory card game where the lowest hand wins. Start a room, share the link and play with friends in the browser.

Stack

  • React
  • TypeScript
  • Node.js
  • Socket.IO
  • Supabase Postgres
  • Docker

Highlights

  • Live games for 2 to 8 players, with every special card power and snap
  • The server runs all the rules, so nobody can peek at cards they shouldn’t see
  • Games get saved after every move and pick back up after a server restart
  • Chat, spectator mode and host controls in each room
  • Bots to fill empty seats when you’re short on players
